# 🍳 Smart Recipe Generator (Resep Pintar)

A lightweight, AI-powered web application that generates step-by-step cooking recipes based on available ingredients. Built during my exploration of Google Developer technologies and Generative AI.

## ✨ Features
- **Smart Ingredient Matching:** Instantly creates practical recipes from whatever ingredients you have in your fridge.
- **Bilingual Support:** Easily toggle between English and Indonesian interfaces.
- **Dynamic Formatting:** Provides clear preparation times, required portions, and structured cooking steps.

## 🛠️ Built With
- **Google AI Studio** - App Builder & Playground
- **Gemini 2.5 Flash** - Fast and lightweight LLM for text generation
- **TypeScript / HTML / CSS** - Frontend interface

## 🚀 How It Works
This application communicates directly with the Gemini API to analyze the input ingredients and cooking style, returning structured markdown recipes in seconds without requiring complex backend servers.
